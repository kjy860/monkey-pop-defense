## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 개요
'몽키 팝 디펜스'는 브라우저에서 별도 설치 없이 즐길 수 있는 캐주얼 2D 타워 디펜스 웹 게임입니다. 유명 게임 '블룬스 타워 디펜스(몽키 디펜스)'의 핵심 메커니즘을 계승하여 원숭이 타워를 길목에 전략적으로 배치하고, 30개 웨이브 동안 쏟아지는 풍선을 터뜨려 기지를 방어합니다.

### 핵심 목표
- **접근성 높은 웹 게임**: 설치나 로그인 없이 링크 접속 즉시 플레이 가능 (브라우저 로컬 저장)
- **난이도별 3종 전용 맵**: 난이도에 맞춘 3가지 고유 트랙(초원, 사막 오아시스, 화산 암석) 제공
- **30개 라운드 및 무한 모드**: 30개 기본 라운드 클리어 후 무한히 몰려오는 '무한 모드(Freeplay)' 지원
- **타격감과 전략성**: Web Audio API로 구현한 실시간 팝/폭발 사운드와 특수 풍선(납, 세라믹, MOAB 비행선) 공략 재미 제공

## 2. 사용자와 사용 시나리오

### 주요 사용자
- 웹 브라우저에서 가볍게 10~20분간 몰입할 전략 퍼즐/디펜스 게임을 찾는 캐주얼 게이머
- 몽키 디펜스 특유의 팝(Pop) 타격감과 타워 육성 배치를 선호하는 사용자

### 사용자 시나리오
1. **게임 시작**: 웹사이트 접속 후 메인 화면에서 난이도(쉬움 / 보통 / 어려움)를 선택하고 '게임 시작' 버튼을 누른다.
2. **타워 배치**: 우측 사이드바에서 보유 골드에 맞는 원숭이 타워(다트 원숭이, 부메랑 원숭이 등)를 선택하여 경로 주변 유효한 타일에 드래그 또는 클릭 배치한다.
3. **웨이브 진행**: '웨이브 시작' 버튼을 눌러 1라운드를 시작한다. 풍선들이 경로를 따라 이동하며 타워의 사거리 안에 들어오면 타워가 자동으로 투사체를 발사해 풍선을 터뜨린다.
4. **수익 창출 및 강화**: 풍선을 터뜨려 획득한 골드로 새로운 타워를 추가 설치하거나, 기존 타워의 공격 속도/사거리/공격력을 업그레이드한다.
5. **게임 결과**: 30번째 웨이브의 최종 보스 풍선을 모두 제거하면 승리 모달이 뜨고, 체력이 0이 되면 게임 오버 화면과 함께 재도전할 수 있다.

## 3. 기능 명세

### 핵심 기능 목록

### 1. 난이도 및 전용 맵 구성
난이도 선택 시 전용 맵과 파라미터가 자동으로 매칭됩니다.
- **쉬움 (Easy) - '초원 구불길' 맵**:
  - 긴 단일 S자 곡선 경로 (길이 약 1,800px, 방어 여유 충분)
  - 시작 골드: 650G / 초기 체력: 150 HP / 적 이동속도 배율: 90% / 타워 비용: 100%
- **보통 (Normal) - '사막 오아시스' 맵**:
  - 중앙 오아시스를 둘러싼 2중 루프 경로 (길이 약 1,350px, 교차 사격 포인트 다수)
  - 시작 골드: 500G / 초기 체력: 100 HP / 적 이동속도 배율: 100% / 타워 비용: 100%
- **어려움 (Hard) - '화산 능선' 맵**:
  - 짧고 직선적인 지그재그 경로 (길이 약 950px, 기지 도달 시간이 매우 빠름)
  - 시작 골드: 400G / 초기 체력: 50 HP / 적 이동속도 배율: 110% / 타워 비용: 115%

### 2. 타워 4종 상세 스펙 및 3단계 업그레이드 규칙
- **1) 다트 원숭이 (Dart Monkey)**: 기본가 200G, 사거리 120px, 발사 간격 0.8초, 피해량 1, 날카로운 투사체 속성
  - Lv 2 (120G): 긴 사거리 (사거리 +30px, 150px)
  - Lv 3 (220G): 연사 다트 (발사 간격 0.8초 -> 0.4초로 단축)
- **2) 압정 타워 (Tack Tower)**: 기본가 280G, 사거리 75px, 발사 간격 1.1초, 8방향 동시 발사, 피해량 1
  - Lv 2 (160G): 압정 폭풍 (8방향 -> 12방향 발사체 증설)
  - Lv 3 (300G): 초고속 압정 분출 (발사 간격 1.1초 -> 0.6초로 단축)
- **3) 폭탄 타워 (Bomb Tower)**: 기본가 350G, 사거리 130px, 발사 간격 1.5초, 폭발 반경 60px, 피해량 2, 폭발 속성(납 풍선 파괴 가능)
  - Lv 2 (200G): 대형 유탄 (폭발 반경 60px -> 95px로 확대)
  - Lv 3 (420G): 미사일 클러스터 (피해량 2 -> 4, 맞은 풍선 주변에 파편 4개 비산)
- **4) 얼음 원숭이 (Ice Monkey)**: 기본가 300G, 사거리 85px, 발사 간격 2.0초, 냉기 파동으로 범위 내 풍선 1.5초간 빙결 정지, 피해량 0
  - Lv 2 (180G): 극저온 확장 (사거리 +25px, 빙결 시간 2.0초로 연장)
  - Lv 3 (350G): 서리 파편 (빙결 해제 시 해당 풍선에 피해량 1 부여)
- **판매 규칙**: 판매 시 해당 타워에 투자된 총 누적 골드(구매가 + 업그레이드 비용)의 70%를 즉시 환급합니다.

### 3. 풍선 스펙 및 30웨이브/무한 모드
- **풍선 종류 및 계층 구조**:
  - 빨강: 체력 1, 속도 1.0, 처치 시 골드 1
  - 파랑: 체력 1 (격파 시 빨강 1 생성), 속도 1.3, 처치 시 골드 2
  - 초록: 체력 1 (격파 시 파랑 1 생성), 속도 1.7, 처치 시 골드 3
  - 노랑: 체력 1 (격파 시 초록 1 생성), 속도 2.2, 처치 시 골드 4
  - 납: 체력 2 (날카로운 공격 면역, 폭탄에만 피격, 격파 시 파랑 2 생성), 속도 0.9, 처치 시 골드 6
  - 세라믹: 겉껍질 체력 8 (모든 공격 유효, 격파 시 노랑 2 생성), 속도 1.8, 처치 시 골드 15
  - MOAB (30웨이브 보스): 비행선 체력 60 (격파 시 세라믹 3 배출), 속도 0.6, 처치 시 골드 100
- **30개 웨이브 구성**:
  - 1~5W: 빨강/파랑 점진적 증대
  - 6~10W: 초록/노랑 무리 및 파랑 대열
  - 11~18W: 빠른 노랑 무리와 납 풍선 최초 등장 (15W부터)
  - 19~24W: 다수의 납 풍선 + 초록/노랑 밀집 무리
  - 25~29W: 세라믹 풍선 군단 및 납 풍선 혼합 공습
  - 30W: 보스 웨이브 - MOAB 1기 + 세라믹/납 호위 편대
- **무한 모드 (Freeplay Mode)**: 30웨이브 클리어 승리 모달에서 '무한 모드 진입' 선택 시 31웨이브부터 체력/속도가 라운드마다 15%/5%씩 영구 증가하며 기지 체력 고갈 시까지 진행

### 4. 게임 조작 및 편의 기능
- 1배속 / 2배속 전환 토글 (물리 델타 타임 2배 적용)
- Spacebar로 웨이브 시작 및 일시정지
- 자동 웨이브 시작(Auto Start) 체크박스: 잔여 풍선이 0이 되면 1초 카운트다운 후 다음 라운드 자동 개시

## 4. 화면과 주소(URL) 구성

### 화면 및 주소 구성 (단일 페이지 SPA)
- **URL 경로**: `/` (단일 페이지 내 뷰포트 상태 전환)

### 화면 레이아웃 구성
1. **상단 네비게이션 헤더 (HUD)**
   - 생명력 표시 (❤️ 하트 + 남은 HP)
   - 보유 골드 (🪙 코인 + 현재 보유량)
   - 현재 라운드 (Round 1 / 30 또는 Freeplay Round 31+)
   - 게임 속도 조절 버튼 (1x / 2x) 및 일시정지 버튼

2. **중앙 게임 캔버스 영역 (800x600 해상도 고정 비율 반응형)**
   - 선택된 난이도 전용 트랙(초원 / 사막 / 화산) 렌더링
   - 타워 배치 유효 구역(초록 원 가이드) 및 불가 구역(빨간 원 가이드) 표시
   - 투사체 궤적 및 풍선 팝 애니메이션 파티클 렌더링

3. **우측 제어 사이드바 패널**
   - 상단: 선택 타워 상세 패널 (이름, 레벨, 업그레이드 비용/버튼, 판매 버튼)
   - 중단: 타워 상점 카드 4종 (단축키 1~4 매핑, 잔여 골드 부족 시 흑백 비활성화)
   - 하단: 대형 '웨이브 시작' 버튼 및 '자동 시작' 토글 체크박스

4. **팝업 모달**
   - **난이도 및 맵 선택 모달**: 게임 시작 시 [초원-쉬움], [사막-보통], [화산-어려움] 카드 3종 중 선택
   - **30라운드 클리어 모달**: '축하합니다! 30스테이지를 방어했습니다.' 문구와 함께 [무한 모드로 계속하기], [메인 메뉴로 가기] 버튼 제공
   - **게임 오버 모달**: 최종 도달 라운드, 처치한 풍선 수 표시 및 [다시 도전하기] 버튼 제공

## 5. 데이터 모델

### 클라이언트 로컬 저장소 스키마 (`localStorage.getItem('monkey_pop_record')`)
별도 서버 없이 브라우저 로컬 스토리지만 사용하여 플레이 기록을 영구 보존합니다.

```typescript
interface GameSaveRecord {
  highestRoundCleared: number; // 전체 최고 클리어 라운드
  difficultyRecords: {
    easy: { cleared: boolean; highestFreeplayRound: number };
    normal: { cleared: boolean; highestFreeplayRound: number };
    hard: { cleared: boolean; highestFreeplayRound: number };
  };
  soundMuted: boolean;
}
```

### 인게임 런타임 엔티티 모델
- **MapConfig**:
  - `id`: 'grass' | 'desert' | 'volcano'
  - `waypoints`: Array<{ x: number; y: number }>
  - `bgTheme`: string
- **Tower**:
  - `id`: string, `type`: 'dart' | 'tack' | 'bomb' | 'ice'
  - `x`: number, `y`: number, `range`: number, `damage`: number
  - `attackSpeed`: number, `level`: number, `totalInvested`: number
- **Balloon**:
  - `id`: string, `type`: 'red' | 'blue' | 'green' | 'yellow' | 'lead' | 'ceramic' | 'moab'
  - `hp`: number, `maxHp`: number, `speed`: number, `pathProgress`: number (0.0 ~ 1.0)
  - `isImmuneToSharp`: boolean, `isFrozen`: boolean, `freezeDuration`: number

## 7. 기술 스택과 폴더 구조

### 기술 스택
- **프레임워크**: React 18 + Vite (TypeScript 5.x)
- **스타일링**: Tailwind CSS v3
- **그래픽 렌더링**: HTML5 Canvas 2D 컨텍스트 (오브젝트 풀링 기반 고성능 렌더러)
- **상태 관리**: Zustand v4 (인게임 엔티티, 경제, 웨이브, UI 상태 분리)
- **오디오 합성**: Web Audio API (외부 mp3 파일 없이 OscillatorNode/GainNode를 활용한 팝 사운드, 펑 사운드 실시간 합성)
- **영속 저장**: 브라우저 `localStorage` API

## 8. 품질 기준 (성능·보안·접근성)

### 품질 및 성능 기준
- **프레임 레이트**: 캔버스 내 100개 이상의 풍선과 50개 이상의 투사체가 동시 활성화되어도 **초당 55~60 FPS** 유지
- **메모리 최적화**: 화면 밖으로 벗어난 투사체와 터진 풍선 오브젝트를 가비지 컬렉터 부담 없이 재사용하는 오브젝트 풀링(Object Pooling) 기법 적용
- **키보드 접근성**: 
  - `Spacebar`: 웨이브 시작 / 일시정지 토글
  - `1`, `2`, `3`, `4`: 해당 단축키로 타워 빠른 선택
  - `Escape`: 타워 선택 해제 및 모달 닫기
- **오류 방지**: 트랙 경로 위나 기존 타워가 있는 타일에는 타워 배치가 불가능하도록 빨간색 사거리 원으로 시각적 오류 피드백 제공

## 10. 테스트 계획

### 핵심 시나리오 수용 기준 (Given - When - Then)

1. **난이도 및 전용 맵 로드 검증**
   - **Given**: 플레이어가 최초 진입 후 난이도 모달에서 '어려움 (화산 능선)'을 클릭했을 때
   - **When**: 인게임 화면이 활성화되면
   - **Then**: 화산 테마 트랙이 캔버스에 그려지고 초기 골드 400G, 초기 체력 50 HP가 정확히 반영된다.

2. **타워 설치 및 골드 차감 검증**
   - **Given**: 보통 난이도(초기 골드 500G) 시작 상태에서
   - **When**: 200G 다트 원숭이를 선택하여 유효한 경로 외 타일에 클릭 배치하면
   - **Then**: 잔여 골드가 300G로 감소하고, 타워가 배치되며 캔버스에 렌더링된다. 경로 위나 겹치는 타일 클릭 시 설치되지 않고 경고 효과가 나타난다.

3. **상성 메커니즘 (납 풍선 vs 폭탄/다트)**
   - **Given**: 납 풍선이 사거리에 진입했을 때
   - **When**: 다트 원숭이가 다트를 발사해 맞히면 체력이 깎이지 않으나, 폭탄 타워가 유탄을 발사해 맞히면 폭발과 함께 2 피해를 입고 파란 풍선 2개로 분열된다.
   - **Then**: 납 풍선이 정상적으로 관통 및 격파된다.

4. **30라운드 클리어 및 무한 모드 전이**
   - **Given**: 30라운드의 MOAB 보스 및 모든 풍선을 전멸시켰을 때
   - **When**: 승리 모달이 출력되고 사용자가 '무한 모드로 계속하기'를 클릭하면
   - **Then**: 모달이 닫히며 HUD의 라운드가 'Freeplay 31'로 전환되고, 웨이브 시작 시 15% 강화된 적들이 정상 스폰된다.

5. **스모크 테스트 (Smoke Routes)**
   - URL: `/`
   - 점검 사항: 캔버스 엘리먼트 렌더링 확인, 맵 선택 모달 출력 확인, Web Audio API 초기화 확인 (브라우저 정책에 맞춰 첫 인터랙션 시 자동 활성화)
