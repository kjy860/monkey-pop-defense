## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 개요
'몽키 팝 디펜스'는 브라우저에서 별도 설치 없이 즐길 수 있는 캐주얼 2D 타워 디펜스 웹 게임입니다. 유명 게임 '블룬스 타워 디펜스(몽키 디펜스)'의 핵심 메커니즘을 계승하여 원숭이 타워를 길목에 전략적으로 배치하고, 100개 웨이브 동안 **100배 폭증하여 다닥다닥 붙어 쏟아지는 압도적인 풍선 물무더기**를 터뜨려 기지를 방어합니다.

### 핵심 목표
- **접근성 높은 웹 게임**: 설치나 로그인 없이 링크 접속 즉시 플레이 가능 (브라우저 로컬 저장)
- **난이도별 3종 전용 맵**: 난이도에 맞춘 3가지 고유 트랙(초원, 사막 오아시스, 화산 암석) 제공
- **100개 라운드 및 무한 모드**: 100개 기본 라운드 클리어 후 무한히 몰려오는 '무한 모드(Freeplay)' 지원
- **100배 초고밀도 물량 & 극한의 빌드 전략**: 100배 스폰 물량에 맞춘 긴장감 넘치는 경제 밸런스와 타워 업그레이드 체계, 단계별 레벨 이펙트로 타격감 극대화

## 2. 사용자와 사용 시나리오

### 주요 사용자
- 웹 브라우저에서 가볍게 10~20분간 몰입할 전략 퍼즐/디펜스 게임을 찾는 캐주얼 게이머
- 몽키 디펜스 특유의 팝(Pop) 타격감과 타워 육성 배치를 선호하는 사용자

### 사용자 시나리오
1. **게임 시작**: 웹사이트 접속 후 메인 화면에서 난이도(쉬움 / 보통 / 어려움)를 선택하고 '게임 시작' 버튼을 누른다.
2. **타워 배치**: 우측 사이드바에서 보유 골드에 맞는 원숭이 타워(다트 원숭이, 부메랑 원숭이 등)를 선택하여 경로 주변 유효한 타일에 드래그 또는 클릭 배치한다.
3. **웨이브 진행**: '웨이브 시작' 버튼을 눌러 1라운드를 시작한다. 풍선들이 경로를 따라 이동하며 타워의 사거리 안에 들어오면 타워가 자동으로 투사체를 발사해 풍선을 터뜨린다.
4. **수익 창출 및 강화**: 풍선을 터뜨려 획득한 골드로 새로운 타워를 추가 설치하거나, 기존 타워의 공격 속도/사거리/공격력을 업그레이드한다.
5. **게임 결과**: 100번째 웨이브의 최종 보스 풍선을 모두 제거하면 승리 모달이 뜨고, 체력이 0이 되면 게임 오버 화면과 함께 재도전할 수 있다.

## 3. 기능 명세

### 핵심 기능 목록

### 1. 난이도 및 전용 맵 구성
난이도 선택 시 전용 맵과 파라미터가 자동으로 매칭됩니다.
- **쉬움 (Easy) - '초원 구불길' 맵**:
  - 긴 단일 S자 곡선 경로 (길이 약 1,800px, 방어 여유 충분)
  - 시작 골드: 1,500G / 초기 체력: 150 HP / 적 이동속도 배율: 90% / 타워 비용: 100%
- **보통 (Normal) - '사막 오아시스' 맵**:
  - 중앙 오아시스를 둘러싼 2중 루프 경로 (길이 약 1,350px, 교차 사격 포인트 다수)
  - 시작 골드: 1,200G / 초기 체력: 100 HP / 적 이동속도 배율: 100% / 타워 비용: 100%
- **어려움 (Hard) - '화산 능선' 맵**:
  - 짧고 직선적인 지그재그 경로 (길이 약 950px, 기지 도달 시간이 매우 빠름)
  - 시작 골드: 1,000G / 초기 체력: 50 HP / 적 이동속도 배율: 110% / 타워 비용: 115%

### 2. 타워 7종 상세 스펙 및 3단계 업그레이드 규칙 (이펙트 강화)
- **엄격한 업그레이드 필수형 경제 밸런스 (100배 물량 대응)**: 웨이브당 생성되는 풍선 총 개수가 기존 대비 **100배**로 폭증하며, 다닥다닥 밀착된 풍선 무리를 관통 및 광역 공격하기 위해 철저한 업그레이드와 타워 조합 없이는 후반 라운드 클리어가 불가능하도록 밸런스가 조정되었습니다.
- **1) 다트 원숭이 (Dart Monkey)**: 기본가 250G, 사거리 120px, 발사 간격 0.7초, 피해량 1
  - Lv 2 (180G): 사거리 150px, 투사체 크기 1.2배 및 궤적 잔상 이펙트 추가
  - Lv 3 (350G): 발사 간격 0.35초로 단축, 양쪽으로 작은 다트 2발 추가 발사(총 3발 산탄) 및 화려한 회전 이펙트
- **2) 압정 타워 (Tack Tower)**: 기본가 320G, 사거리 85px, 발사 간격 1.0초, 8방향 사방 확산 팝(Pop) 데미지 적용 (풍선 감지 및 관통 판정 완벽 수정 완료)
  - Lv 2 (220G): 12방향 압정 발사, 불꽃 파티클이 흩날리는 이펙트 추가
  - Lv 3 (420G): 발사 간격 0.5초로 단축, 사방으로 거대한 불타는 압정 링이 퍼져나가는 고속 회전 이펙트
- **3) 폭탄 타워 (Bomb Tower)**: 기본가 450G, 사거리 130px, 발사 간격 1.3초, 폭발 반경 65px, 피해량 2 (납 파괴 가능)
  - Lv 2 (300G): 폭발 반경 100px, 폭발 시 주황색 화염 파티클 16개 비산
  - Lv 3 (600G): 피해량 4, 거대한 네이팜 폭발 이펙트와 함께 주변에 2차 파편 8개 비산 및 화면 미세 진동(Screen Shake)
- **4) 얼음 원숭이 (Ice Monkey)**: 기본가 380G, 사거리 85px, 발사 간격 1.8초, 냉기 파동(1.5초 빙결)
  - Lv 2 (250G): 사거리 110px, 빙결 시간 2.0초, 서리 결정 크리스탈 파티클 확장
  - Lv 3 (500G): 서리 파편(빙결 해제 시 피해량 1), 타워 주변에 눈보라 오라(Blizzard Aura) 지속 이펙트 렌더링
- **5) 부메랑 원숭이 (Boomerang Monkey)**: 기본가 350G, 사거리 140px, 발사 간격 1.1초, 곡선 궤도로 적 관통 공격(피해량 2)
  - Lv 2 (240G): 사거리 170px, 부메랑 2개 동시 회전 발사
  - Lv 3 (480G): 거대한 불타는 화염 부메랑이 넓은 호를 그리며 다중 적 다단 히트
- **6) 저격수 원숭이 (Sniper Monkey)**: 기본가 600G, 사거리 전면 무한, 발사 간격 2.0초, 맵 어디든 즉시 명중 (피해량 3, 납 파괴 불가)
  - Lv 2 (400G): 발사 간격 1.2초, 피해량 5로 증가
  - Lv 3 (800G): 관통 탄환 장착, 일직선 상의 적 최대 5마리 동시 관통 타격 및 레이저 레이스 이펙트
- **7) 마법사 원숭이 (Wizard Monkey)**: 기본가 550G, 사거리 110px, 발사 간격 0.9초, 유도 화염구 발사 (피해량 2, 납/세라믹 특화)
  - Lv 2 (350G): 화염구 폭발 범위 추가 및 화염 지속 도트 데미지(Burn)
  - Lv 3 (700G): 거대한 용오름 마법 폭풍 소환, 범위 내 모든 풍선을 연속 타격하는 드래곤 브레스 이펙트
- **판매 규칙**: 판매 시 투자된 총 누적 골드의 70% 환급

### 3. 풍선 스펙 및 100웨이브/무한 모드
- **풍선 종류 및 계층 구조**: 빨강(1G) -> 파랑(2G) -> 초록(3G) -> 노랑(4G) -> 납(6G, 폭탄/마법 격파) -> 세라믹(15G) -> MOAB(100G) / BFB(250G, 50W 이상 보스) / ZOMG(600G, 100W 최종 보스)
- **100배 초고밀도 스폰 시스템**: 각 웨이브별 스폰되는 총 풍선 개수와 동시 등장 밀도가 기존 디펜스 대비 **100배**로 폭증하여, 트랙 전체가 다닥다닥 붙은 풍선들로 꽉 채워지는 압도적인 웨이브 러시 연출
- **100개 웨이브 구성**:
  - 1~20W: 초급 풍선 100배 물량 폭증 및 납 풍선 집중 등장
  - 21~50W: 세라믹 군단 및 강력한 대형 비행선(BFB) 러시
  - 51~99W: 고속 복합 밀집 러시 및 다중 비행선 편대 방어전
  - 100W: 최종 보스 웨이브 - ZOMG 비행선 및 수많은 MOAB/세라믹 호위 편대
- **무한 모드 (Freeplay Mode)**: 100웨이브 클리어 승리 모달에서 '무한 모드 진입' 선택 시 101웨이브부터 체력/속도가 라운드마다 기하급수적으로 증가하며 진행

### 4. 게임 조작 및 편의 기능
- 1배속 / 2배속 전환 토글
- Spacebar로 웨이브 시작 및 일시정지
- **자동 웨이브 시작(Auto Start) 버그 방어 로직**: 잔여 풍선이 0이 되고 라운드가 정상 정산된 이후에만 1초 카운트다운 후 다음 라운드로 전환되도록 상태 체크 루틴을 엄격히 분리하여 라운드가 무한정 급상승하는 버그 원천 차단

## 4. 화면과 주소(URL) 구성

### 화면 및 주소 구성 (단일 페이지 SPA)
- **URL 경로**: `/` (단일 페이지 내 뷰포트 상태 전환)

### 화면 레이아웃 구성
1. **상단 네비게이션 헤더 (HUD)**
   - 생명력 표시 (❤️ 하트 + 남은 HP)
   - 보유 골드 (🪙 코인 + 현재 보유량)
   - 현재 라운드 (Round 1 / 100 또는 Freeplay Round 101+)
   - 게임 속도 조절 버튼 (1x / 2x) 및 일시정지 버튼

2. **중앙 게임 캔버스 영역 (800x600 해상도 고정 비율 반응형)**
   - 선택된 난이도 전용 트랙(초원 / 사막 / 화산) 렌더링
   - 7종 타워의 업그레이드 레벨(Lv.1 ~ Lv.3)에 따라 점진적으로 화려해지는 투사체 및 타격/폭발 이펙트 렌더링
   - 압정 타워의 사방 확산 팝 판정 시각화 영역 및 타워 배치 유효 구역(초록 원) 가이드

3. **우측 제어 사이드바 패널**
   - 상단: 선택 타워 상세 패널 (이름, 레벨, 업그레이드 비용/버튼, 판매 버튼)
   - 중단: 타워 상점 카드 7종 그리드 스크롤 (다트, 압정, 폭탄, 얼음, 부메랑, 저격수, 마법사)
   - 하단: 대형 '웨이브 시작' 버튼 및 '자동 시작' 토글 체크박스

4. **팝업 모달**
   - **난이도 및 맵 선택 모달**: 게임 시작 시 [초원-쉬움], [사막-보통], [화산-어려움] 카드 3종 중 선택
   - **100라운드 클리어 모달**: '축하합니다! 100스테이지를 방어했습니다.' 문구와 함께 [무한 모드로 계속하기], [메인 메뉴로 가기] 버튼 제공
   - **게임 오버 모달**: 최종 도달 라운드, 처치한 풍선 수 표시 및 [다시 도전하기] 버튼 제공

## 7. 기술 스택과 폴더 구조

- **스타일링**: Tailwind CSS v3
- **그래픽 렌더링**: HTML5 Canvas 2D 컨텍스트 (오브젝트 풀링 기반 고성능 렌더러 - 풍선 100배 물량 최적화)
- **상태 관리**: Zustand v4 (인게임 엔티티, 경제, 웨이브, UI 상태 분리)
- **오디오 합성**: Web Audio API (외부 mp3 파일 없이 OscillatorNode/GainNode를 활용한 팝 사운드, 펑 사운드 실시간 합성)
- **영속 저장**: 브라우저 `localStorage` API

## 8. 품질 기준 (성능·보안·접근성)

### 품정 및 성능 기준
- **프레임 레이트**: 캔버스 내 1,000개 이상의 다닥다닥 붙은 풍선과 200개 이상의 투사체가 동시 활성화되어도 **초당 55~60 FPS** 유지
- **메모리 최적화**: 100배 물량 스폰에 대응하기 위해 화면 밖으로 벗어난 투사체와 터진 풍선 오브젝트를 가비지 컬렉터 부담 없이 재사용하는 엄격한 오브젝트 풀링(Object Pooling) 및 오프스크린 캔버스 렌더링 최적화 적용
- **키보드 접근성**: 
  - `Spacebar`: 웨이브 시작 / 일시정지 토글
  - `1`, `2`, `3`, `4`: 해당 단축키로 타워 빠른 선택
  - `Escape`: 타워 선택 해제 및 모달 닫기
- **오류 방지**: 트랙 경로 위나 기존 타워가 있는 타일에는 타워 배치가 불가능하도록 빨간색 사거리 원으로 시각적 오류 피드백 제공

## 10. 테스트 계획

### 핵심 시나리오 수용 기준 (Given - When - Then)

1. **난이도 및 전용 맵 로드 검증**
   - **Given**: 플레이어가 최초 진입 후 난이도 모달에서 '어려움 (화산 능선)'을 클릭했을 때
   - **When**: 인게임 화면이 활성화되면
   - **Then**: 화산 테마 트랙이 캔버스에 그려지고 초기 골드 1,000G, 초기 체력 50 HP가 정확히 반영된다.

2. **타워 7종 설치 및 업그레이드 이펙트 검증**
   - **Given**: 100배 풍선 물량을 터뜨려 골드를 충분히 획득했을 때
   - **When**: 압정 타워를 설치하고 다트/부메랑/저격수/마법사 타워를 Lv.3까지 업그레이드하면
   - **Then**: 압정 타워가 정상적으로 주변 풍선을 터뜨으며, 각 타워별 고유 투사체와 화려한 회전/불꽃/레이저 이펙트가 캔버스에 렌더링된다.

3. **자동 웨이브 시작 버그 방어 검증**
   - **Given**: 자동 웨이브 시작(Auto Start) 체크박스가 켜진 상태에서 100배 물량의 라운드 5 풍선이 모두 격파되었을 때
   - **When**: 웨이브 정산이 완료되면
   - **Then**: 1초 카운트다운 후 정확히 라운드 6으로 1회만 진입하며, 라운드가 연속으로 급상승하는 오작동이 발생하지 않는다.

4. **100라운드 클리어 및 무한 모드 전이**
   - **Given**: 100라운드의 ZOMG 보스 및 모든 풍선을 전멸시켰을 때
   - **When**: 승리 모달이 출력되고 사용자가 '무한 모드로 계속하기'를 클릭하면
   - **Then**: 모달이 닫히며 HUD의 라운드가 'Freeplay 101'로 전환되고 게임이 정상 지속된다.

5. **스모크 테스트 (Smoke Routes)**
   - URL: `/`
   - 점검 사항: 캔버스 엘리먼트 렌더링 확인, 7종 타워 상점 UI 확인, 압정 타워 팝 판정 확인, 100배 풍선 밀집 물량 스폰 및 자동 시작 토글 정상 동작 확인
