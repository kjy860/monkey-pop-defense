## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 개요
'몽키 팝 디펜스'는 브라우저에서 별도 설치 없이 즐길 수 있는 캐주얼 2D 타워 디펜스 웹 게임입니다. 유명 게임 '블룬스 타워 디펜스(몽키 디펜스)'의 핵심 메커니즘을 계승하여 원숭이 타워를 길목에 전략적으로 배치하고, 100개 웨이브 동안 쏟아지는 풍선을 터뜨려 기지를 방어합니다.

### 핵심 목표
- **접근성 높은 웹 게임**: 설치나 로그인 없이 링크 접속 즉시 플레이 가능 (브라우저 로컬 저장)
- **난이도별 3종 전용 맵**: 난이도에 맞춘 3가지 고유 트랙(초원, 사막 오아시스, 화산 암석) 제공
- **100개 라운드 및 무한 모드**: 100개 기본 라운드 클리어 후 무한히 몰려오는 '무한 모드(Freeplay)' 지원
- **풍부한 경제와 타격감**: 풍선 처치 골드 상향으로 다채로운 타워 빌드와 업그레이드를 즐기며, Web Audio API 및 단계별 레벨 이펙트로 타격감 극대화

## 2. 사용자와 사용 시나리오

### 주요 사용자
- 웹 브라우저에서 가볍게 10~20분간 몰입할 전략 퍼즐/디펜스 게임을 찾는 캐주얼 게이머
- 몽키 디펜스 특유의 팝(Pop) 타격감과 타워 육성 배치를 선호하는 사용자

### 사용자 시나리오
1. **게임 시작**: 웹사이트 접속 후 메인 화면에서 난이도(쉬움 / 보통 / 어려움)를 선택하고 '게임 시작' 버튼을 누른다.
2. **타워 배치**: 우측 사이드바에서 보유 골드에 맞는 원숭이 타워(다트 원숭이, 부메랑 원숭이 등)를 선택하여 경로 주변 유효한 타일에 드래그 또는 클릭 배치한다.
3. **웨이브 진행**: '웨이브 시작' 버튼을 눌러 1라운드를 시작한다. 풍선들이 경로를 따라 이동하며 타워의 사거리 안에 들어오면 타워가 자동으로 투사체를 발사해 풍선을 터뜨린다.
4. **수익 창출 및 강화**: 풍선을 터뜨려 획득한 골드로 새로운 타워를 추가 설치하거나, 기존 타워의 공격 속도/사거리/공격력을 업그레이드한다.
5. **게임 결과**: 30번째 웨이브의 최종 보스 풍선을 모두 제거하면 승리 모달이 뜨고, 체력이 0이 되면 게임 오버 화면과 함께 재도전할 수 있다.

## 3. 기능 명세

### 핵심 기능 목록

### 1. 난이도 및 전용 맵 구성
난이도 선택 시 전용 맵과 파라미터가 자동으로 매칭됩니다.
- **쉬움 (Easy) - '초원 구불길' 맵**:
  - 긴 단일 S자 곡선 경로 (길이 약 1,800px, 방어 여유 충분)
  - 시작 골드: 750G / 초기 체력: 150 HP / 적 이동속도 배율: 90% / 타워 비용: 100%
- **보통 (Normal) - '사막 오아시스' 맵**:
  - 중앙 오아시스를 둘러싼 2중 루프 경로 (길이 약 1,350px, 교차 사격 포인트 다수)
  - 시작 골드: 600G / 초기 체력: 100 HP / 적 이동속도 배율: 100% / 타워 비용: 100%
- **어려움 (Hard) - '화산 능선' 맵**:
  - 짧고 직선적인 지그재그 경로 (길이 약 950px, 기지 도달 시간이 매우 빠름)
  - 시작 골드: 500G / 초기 체력: 50 HP / 적 이동속도 배율: 110% / 타워 비용: 115%

### 2. 타워 4종 상세 스펙 및 3단계 업그레이드 규칙 (이펙트 강화)
- **골드 경제 밸런스**: 모든 풍선 처치 시 획득 골드가 기본 스펙 대비 약 1.5~2배 상향되어 더 많은 타워 설치와 3단계 업그레이드를 빠르게 경험할 수 있습니다.
- **1) 다트 원숭이 (Dart Monkey)**: 기본가 200G, 사거리 120px, 발사 간격 0.8초, 피해량 1
  - Lv 2 (120G): 사거리 150px, 투사체 크기 1.2배 및 궤적 잔상 이펙트 추가
  - Lv 3 (220G): 발사 간격 0.4초로 단축, 양쪽으로 작은 다트 2발 추가 발사(총 3발 산탄) 및 화려한 회전 이펙트
- **2) 압정 타워 (Tack Tower)**: 기본가 280G, 사거리 75px, 발사 간격 1.1초, 8방향 발사, 피해량 1
  - Lv 2 (160G): 12방향 압정 발사, 불꽃 파티클이 흩날리는 이펙트 추가
  - Lv 3 (300G): 발사 간격 0.6초로 단축, 사방으로 거대한 불타는 압정 링이 퍼져나가는 고속 회전 이펙트
- **3) 폭탄 타워 (Bomb Tower)**: 기본가 350G, 사거리 130px, 발사 간격 1.5초, 폭발 반경 60px, 피해량 2 (납 파괴 가능)
  - Lv 2 (200G): 폭발 반경 95px, 폭발 시 주황색 화염 파티클 12개 비산
  - Lv 3 (420G): 피해량 4, 거대한 네이팜 폭발 이펙트와 함께 주변에 2차 파편 6개 비산 및 화면 미세 진동(Screen Shake)
- **4) 얼음 원숭이 (Ice Monkey)**: 기본가 300G, 사거리 85px, 발사 간격 2.0초, 냉기 파동(1.5초 빙결)
  - Lv 2 (180G): 사거리 110px, 빙결 시간 2.0초, 서리 결정 크리스탈 파티클 확장
  - Lv 3 (350G): 서리 파편(빙결 해제 시 피해량 1), 타워 주변에 눈보라 오라(Blizzard Aura) 지속 이펙트 렌더링
- **판매 규칙**: 판매 시 투자된 총 누적 골드의 70% 환급

### 3. 풍선 스펙 및 100웨이브/무한 모드
- **풍선 종류 및 계층 구조**: 빨강(1G) -> 파랑(2G) -> 초록(3G) -> 노랑(4G) -> 납(6G, 폭탄만 격파) -> 세라믹(15G) -> MOAB(100G) / BFB(250G, 50W 이상 보스) / ZOMG(600G, 100W 최종 보스)
- **100개 웨이브 구성**:
  - 1~20W: 초급 풍선 물량 및 납 풍선 등장
  - 21~50W: 세라믹 군단 및 첫 번째 대형 비행선(BFB) 등장
  - 51~99W: 고속 복합 러시 및 다중 비행선 편대
  - 100W: 최종 보스 웨이브 - ZOMG 비행선 및 다수의 MOAB/세라믹 호위 편대
- **무한 모드 (Freeplay Mode)**: 100웨이브 클리어 승리 모달에서 '무한 모드 진입' 선택 시 101웨이브부터 체력/속도가 라운드마다 증가하며 진행

### 4. 게임 조작 및 편의 기능 (버그 수정 포함)
- 1배속 / 2배속 전환 토글
- Spacebar로 웨이브 시작 및 일시정지
- **자동 웨이브 시작(Auto Start) 버그 수정**: 잔여 풍선이 0이 되고 라운드가 정상 정산된 이후에만 1초 카운트다운 후 다음 라운드로 전환되도록 상태 체크 로직을 엄격히 분리하여 라운드가 무한정 급상승하는 버그 차단
