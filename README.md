# 몽키 팝 디펜스 (Monkey Pop Defense)

별도 설치 없이 웹 브라우저에서 바로 즐기는 캐주얼 2D 타워 디펜스 게임입니다.
원숭이 타워를 도로 주변에 전략적으로 배치하고, 30개 웨이브 동안 쏟아지는 풍선을 터뜨려 기지를 방어하세요!

---

## 1. 실행 방법 (비전문가용 안내)

### 사전 준비물
- **Node.js (버전 20 이상)** 설치 필요 ([https://nodejs.org](https://nodejs.org) 에서 LST 버전 다운로드 가능)

### 단계별 실행 순서

1. **프로젝트 폴더로 이동**
   터미널(명령 프롬프트 또는 PowerShell)을 열고 본 프로젝트 폴더로 이동합니다.

2. **의존성 패키지 설치**
   아래 명령어를 입력하여 실행에 필요한 관련 라이브러리들을 설치합니다.
   ```bash
   npm install
   ```

3. **개발 서버 실행 (게임 플레이)**
   아래 명령어를 입력하여 게임을 실행합니다.
   ```bash
   npm run dev
   ```
   실행 후 터미널에 나타나는 주소(예: `http://localhost:5173`)를 클릭하거나 웹 브라우저 주소창에 입력하면 게임을 플레이할 수 있습니다.

4. **테스트 실행 (선택 사항)**
   게임 시스템의 안정성과 규칙 검증 테스트를 진행할 수 있습니다.
   ```bash
   npm run test
   ```

5. **프로덕션 빌드 (선택 사항)**
   실제 배포용 파일로 번들링을 수행합니다.
   ```bash
   npm run build
   ```

## 2. 게임 조작법 및 단축키

- **스페이스바 (`Spacebar`)**: 웨이브 시작 / 일시정지
- **숫자키 `1` ~ `4`**:
  - `1`: 다트 원숭이 선택 (200G)
  - `2`: 압정 타워 선택 (280G)
  - `3`: 폭탄 타워 선택 (350G)
  - `4`: 얼음 원숭이 선택 (300G)
- **`ESC`**: 타워 선택 해제 및 모달 닫기
- **배속 토글**: 상단 HUD의 `1x` / `2x` 버튼으로 게임 속도 2배속 전환 가능
- **자동 시작 (Auto Start)**: 우측 사이드바 하단 체크박스를 활성화하면 잔여 풍선이 0이 될 때 다음 라운드가 자동 개시됩니다.

## 3. 게임 시스템 안내

### 난이도 및 맵
- **쉬움 (초원 구불길)**: 여유로운 긴 S자 경로 / 시작 골드 650G / 체력 150 HP
- **보통 (사막 오아시스)**: 교차 사격 가능한 2중 루프 경로 / 시작 골드 500G / 체력 100 HP
- **어려움 (화산 능선)**: 빠르고 짧은 지그재그 경로 / 시작 골드 400G / 체력 50 HP

### 타워 및 상성
- **다트 원숭이**: 기본 공격 및 빠른 연사 타워
- **압정 타워**: 8방향/12방향 전방위 압정 발사
- **폭탄 타워**: 광역 폭발 피해 (단단한 **납 풍선**을 터뜨릴 수 있음)
- **얼음 원숭이**: 주변 풍선 둔화 및 빙결 정지

### 무한 모드 (Freeplay)
- 30라운드의 최종 보스 비행선 **MOAB**을 격파하면 승리합니다.
- 승리 후 **'무한 모드로 계속하기'**를 선택하면 라운드마다 강화되는 적들에 계속 도전할 수 있습니다.
